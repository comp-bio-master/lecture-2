# Lecture 2: Pipelines, Scripts, and Loops

Follow the [Lecture 2 instructions](https://github.com/tamucc-comp-bio/classroom_repo_2026/blob/main/lectures/lecture02.md) while working in your terminal.

Copy its SSH address from **Code → SSH**. Replace `YOUR-COPIED-SSH-ADDRESS` below with that address:

```text
cd ~
git clone YOUR-COPIED-SSH-ADDRESS lecture-2
cd lecture-2
```

If you already cloned it, enter your existing clone instead.

* `CSB/unix/data/` contains supplied input data. Keep these files unchanged.
* `CSB/unix/sandbox/` is where you save your scripts, results, and notes.

Start the exercises here:

```bash
cd ~/lecture-2/CSB/unix/sandbox
```

At the end, commit and push from your Lecture 2 clone:

```bash
cd ~/lecture-2
git status
git add --all
git commit -m "Complete Lecture 2 pipelines and scripts"
git push
```

Refresh your personal repository on GitHub to check your work arrived. Linked quizzes and exercise forms must also be submitted separately.
