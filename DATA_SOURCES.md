# Data sources

These files are a subset of the CSB teaching data already distributed in Assignment 1. No data values were changed.

Source snapshot: [Assignment 1 reference repository, commit a15fe08660dfabeec6a8a8b466307ecf048b32e2](https://github.com/tamucc-comp-bio-assignments/comp-bio-skills-2026-assignment-1-cbird808/tree/a15fe08660dfabeec6a8a8b466307ecf048b32e2/CSB/unix/data).

The CSB materials accompany *Computing Skills for Biologists: A Toolbox* by Stefano Allesina and Madlen Wilmes (Princeton University Press, 2019). [Original CSB repository](https://github.com/CSB-book/CSB).

Retained data descriptions:

* [Saavedra plant–pollinator networks](CSB/unix/data/Saavedra2013_about.txt)
* [MicroRNA data](CSB/unix/data/miRNA/miRNA_about.txt)
